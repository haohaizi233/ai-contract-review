## 3. CI/CD 安全扫描与门禁闭环规范

1. **结构性安全拦截**：
   - 严禁任何 `.docx` 合同原件提交至仓库（`tests/fixtures/` 仅允许合法合成脱敏夹具）；
   - 严禁 `参考/`、`_tools/`、`data/` 等受控原始目录入库。
2. **凭据特征正则扫描**：
   - 全目录扫描私钥特征（`BEGIN RSA/EC PRIVATE KEY`）、企业微信 Secret、MySQL 命令行密码明文等；
   - 发现命中立即返回非零失败码阻断构建，且日志脱敏只展示文件路径与行号，不回显匹配内容。
3. **企业敏感实体扫描（Fail-Closed 模式）**：
   - 当环境变量声明 `REQUIRE_SENSITIVE_MARKERS_SECRET=1` 时，若未提供 `SENSITIVE_MARKERS` Secret，CI 必须立即失败，严禁静默跳过假绿灯。
