恢复过程、输入转换、查找及验证日志位于 tmp/recovery_20261109。该目录仅用于本次恢复，日常新合并请使用正式入口。

## 防止再次覆盖
live_db_merge.py 默认输出至带微秒时间戳的新目录。--out 仅接受不存在的目录，内部执行入口也通过独占创建拒绝已有目录。已移除递归删除逻辑。运行中断保留独立目录，重试需指定新目录。
示例：
python tools/live_db_merge.py --out data/contract_merged_run_新批次

新合并结果需独立验收后再切换当前目录，保留上一版。全量附件和图片应另做独立备份，Git 不存储这些资产。禁止用旧验收 JSON 或目录文件总数判断资源完整。

资源缺失逐项清单：data/contract_merged/recovery_missing_assets.csv。额外图片转码扫描遇到多张超大附件图片，已停止该补充扫描，未完成全量转码比对；因此不据此断言所有图片都无法恢复。原始字节哈希比对完成，未找到额外相同内容副本。后续可按缺失清单从来源重新导出，恢复图片编译产物。
