## 官方资料核实

本次直接读取官方 HTML 正文，避免搜索摘要、文档镜像和旧版本示例混淆。

- [微盘概述](https://developer.work.weixin.qq.com/document/path/93654)：应用可通过接口创建空间并成为超级管理员；配置入口为「协作 → 微盘 → API」。应用空间内通知范围成员仅下载/预览，不能把迁入应用空间当成保留原协作方式的等价方案。
- [创建空间](https://developer.work.weixin.qq.com/document/path/93655)：创建者为应用本身。
- [获取文件列表](https://developer.work.weixin.qq.com/document/path/93657)：当前请求参数不含 userid；不能依赖补传管理员 userid 解决应用身份限制。
- [下载文件](https://developer.work.weixin.qq.com/document/path/97881)：支持 fileid 或 selected_ticket 二选一；只支持普通文件，不支持文件夹、微文档。
- [当前选择文件 JSAPI](https://developer.work.weixin.qq.com/document/path/99154)：返回文件 URL 等信息；不能未经验证就承诺用选择器取得永久目录下载授权。
- [选择目录 JSAPI](https://developer.work.weixin.qq.com/document/path/99009)：临时 ticket 用于上传，有期限和次数限制，不能当作后台永久遍历授权。
- [官方更新日志](https://developer.work.weixin.qq.com/document/path/93221)：2022-12-01 微盘接口操作维度由成员改为应用；2026-08-17 官方 CLI 增加微盘上传、检索、下载能力。旧 HiFlow 成员身份说明不足以证明当前自建应用支持同样调用方式。
