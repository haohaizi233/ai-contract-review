> **状态评级标准**：  
> - **MITIGATED (已缓解)**：已通过系统架构、状态机、代码审查与自动化测试闭环；

| **R01** | **权限配置** | 企业微信微盘管理后台的自建应用授权范围无法通过开放 API 接口反查，无法由程序探知该空间是否已被列入后台 API 白名单。 | 中 / 中 | 在诊断报告中明确给出后台核实路径（协作 → 微盘 → API → 可调用接口的应用），标记为非程序可自动验证项；同时采用本地客户端同步方案规避该权限壁垒。 | `MANUAL_VERIFICATION_REQUIRED` |
| **R02** | **数据完整性** | Windows 桌面端默认开启“按需同步 / 云端占位符”（Files-on-Demand）。当文件未被预先下载时，可能出现 0 字节占位或只读阻塞。 | 高 / 中 | 1. 制定运维操作 SOP：在客户端对法务部文件夹勾选“始终保留在此设备上”；<br>2. 系统加固：`check_file_stability` 自动检查大小与独占读，未完全下载前保持 `WAITING_STABLE`，严禁半入库。 | `MITIGATED` |
| **R03** | **事务一致性** | 知识库母本在迭代更新或增量热替换过程中，若发生崩溃可能导致 FTS5 倒排索引与向量表不一致。 | 高 / 低 | `Storage.upsert_document` 采用 SQLite 单一原子事务（`BEGIN IMMEDIATE TRANSACTION`），条款插入与索引更新在同一事务内完成，失败全量回滚。 | `MITIGATED` |
| **R04** | **误删防抖** | 业务人员在微盘中临时重命名、移动子文件夹或遭遇客户端同步抖动，导致文件在磁盘上短暂消失。 | 高 / 中 | 设立宽限期机制（`removal_grace_seconds=60.0`），文件消失首先进入 `PENDING_REMOVAL` 挂起；超时后仅置为 `INACTIVE` 软删除，绝不硬删除母本与索引；文件恢复即时激活。 | `MITIGATED` |
| **R05** | **安全越界** | 监控目录内若出现符号链接（Symlink）或恶意构造的 `../` 路径，可能导致读取微盘监控目录以外的系统敏感文件。 | 极高 / 极低 | 强制执行 `Path.resolve()` 规范化路径计算，比对绝对路径前缀必须严格匹配 `watch_dir`，否则抛出越界告警并直接跳过。 | `MITIGATED` |
| **R06** | **资源可用性** | 业务人员上传超大（>20MB）或损坏的 PDF/DOCX，可能导致内存激增或解析器死循环挂起。 | 中 / 中 | 1. 文件大小硬上限阈值判定（>20MB 拒绝并记录告警）；<br>2. 深度格式嗅探（DOCX XML 解压安全校验、PDF `%PDF` 魔数校验）；<br>3. 损坏文件转入 `QUARANTINED` 状态，不阻塞其他文件的扫描同步。 | `MITIGATED` |
| **R07** | **网络与网络安全** | 本地外网出口 IP 为家庭宽带或移动办公动态 IP，若采用企微 API 直连，IP 频繁变动会导致 `60020` 拦截。 | 高 / 极高 | **采纳官方客户端本地映射同步架构**：微盘桌面端自带企业级长连接通道（不受可信 IP 限制），Python 同步工具纯本地读取，彻底消除 IP 白名单风险。 | `MITIGATED` |
| **R08** | **并发写冲突** | 多个同步进程或检索服务同时对 SQLite 数据库发起写入，可能触发 `sqlite3.OperationalError: database is locked`。 | 中 / 低 | 1. 采用 `threading.Lock()` 与互斥标记防重入；<br>2. SQLite 连接开启 WAL 模式（`PRAGMA journal_mode=WAL`），支持单写多读并发；<br>3. 写入事务失败具备 `FAILED_RETRYABLE` 自愈重试能力。 | `MITIGATED` |

## 二、关键风险核查与处置 SOP

### 2.1 R01：企微管理后台人工复核 SOP (如仍需评估 API 模式)

如果企业未来需要切换回微盘官方 API 直连模式，企业微信超级管理员必须在管理后台完成以下两项确认：
1. **应用白名单配置**：
   - 路径：`管理后台 → 协作 → 微盘 → API → 可调用接口的应用`
   - 检查：应用“AI 合同知识库同步”（AgentID `1000077`）是否在清单中；
2. **空间调用范围**：
   - 检查该应用的授权范围是勾选了 **“全部空间”** 还是 **“指定空间”**；
   - 若为“指定空间”，必须将目标空间（`法律事务部（含商务合同等文件）`）显式添加进授权列表。

### 2.2 R02：微盘本地离线防脱水操作 SOP

为保证本地 RAG 守护进程不受云端按需脱水影响，请按以下步骤配置当前机器的企业微信桌面端：
1. 在 Windows 任务栏通知区域找到“企业微信”图标；
2. 打开企业微信主界面，点击左侧导航栏 **“微盘”**；
3. 展开企业目录，找到 **“恒程创新 → 法律事务部（含商务合同等文件）”**；
4. 鼠标右键点击该文件夹，在弹出菜单中选择 **“始终保留在此设备上”**（或 **“全部下载”**）；
5. 待文件夹右侧绿色对勾图标全部亮起，即代表所有合同已完整下载至本地 NTFS 磁盘。
